# Number Guessing Game

A Python-based number guessing game where the player tries to guess a randomly generated number between 1 and 100.

## Features

- Generates a random number between 1 and 100
- Accepts user guesses
- Provides Too High / Too Low hints
- Dynamically narrows the possible number range
- Rejects invalid inputs
- Counts valid attempts

## Technologies Used

- Python
- Random module

## How to Run

1. Open the project folder in a terminal.
2. Run:

```bash
python main.py
